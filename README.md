# Desafio Técnico - Target Sistemas

Soluções desenvolvidas para o desafio técnico utilizando Python, com foco em organização, validação de regras de negócio e testes automatizados.

## Objetivo

Implementar as soluções propostas no desafio, contemplando:

1. Cálculo de comissão de vendedores.
2. Controle de movimentações de estoque.
3. Cálculo de juros por atraso.

## Tecnologias utilizadas

- Python 3.11
- Pytest
- Biblioteca padrão do Python
